# 豆瓣中心

DoubanCenter 是 MoviePilot V3 插件，用于同步豆瓣榜单、豆瓣时间和“想看”列表，
并提供自动订阅、观察期治理、归档记录和仪表盘概览。

## 使用

在 MoviePilot 插件配置中启用后，可按需配置豆瓣 Cookie、CookieCloud、RSS 榜单、
自动订阅和观察期策略。豆瓣 Cookie 留空时，插件会按宿主 CookieCloud 配置读取
`douban.com` Cookie。

插件使用 Vue 联邦界面，运行资源位于 `dist/assets/remoteEntry.js` 及其关联文件。

`v3.0.16`：榜单订阅增加观察通知开关（默认关闭）与通知分类（默认“插件”）。
新条目进入观察区时提醒，同一观察周期、同一渠道最多尝试发送一次；升级存量不补发。
Telegram 绑定有效管理员个人 ID 且该渠道启用对应通知分类时，通知提供“立即订阅”和
“移除观察”；没有绑定或其他渠道发送普通通知，可通过链接打开插件观察区。
立即订阅保留媒体身份和季号；移除只忽略并归档该榜单条目，不删除已有订阅、下载或文件。
按钮有效期为 7 天，绑定当前实例、用户、渠道和观察周期；重复点击、旧状态或未知执行结果
不会重复提交。通知提交不代表客户端已送达；禁用通知、切换绑定或关闭该榜单观察后旧按钮失效。

想看同步向订阅服务传递条目标题、年份和季号，保留原始条目标题；
已有第一季的订阅、完成历史或媒体库记录不再误拦第二季。想看定时服务独立启停，
关闭豆瓣时间不影响想看同步；关闭插件总开关或想看开关仍停止该服务。
已处理的旧想看条目不会自动重新订阅，需核对后定向恢复。

直接解析豆瓣 dispatch、移动端电影与电视剧链接中的编号，保留榜单过滤参数；
已有编号时不再额外请求 rexxar，缺失时最多查询一次、最多 50 条，按唯一标题匹配，
不再依赖榜单排序；同名歧义、已知年份或类型冲突不补编号。过滤路径仍保留原有跳过兜底规则。

保留想看失败队列与手动订阅季号，阻止停止后的旧任务继续写入；
修复弹窗识别状态，隔离离页和切换实例后的异步回执，并适配矮屏配置与透明详情布局；豆瓣中心其他通知仍归类为“插件”；父级剧集缓存限制为 256 条，成功结果保留 5 分钟、失败结果保留 1 分钟，停止时释放。
过滤非播放事件，仅凭明确登录响应告警；网络、风控和未知页面不再误报 Cookie 失效或想看同步失败。

电影优先使用按媒体身份匹配的 Emby 主海报，兼容已有电影档案，保留原始海报作为回退。
观影档案以媒体库实际入库季为准，一季一条，使用入库集表和首播日期核验豆瓣主条目。
库内整季不按豆瓣 Part 再拆分，展示标题不追加季号或 Part。海报优先使用媒体库对应季图片，
不可用时保留原档案海报；身份有歧义时保留待核验状态。

首次播放、最近播放、已看标记和豆瓣同步时间分别记录。第 1 集即使跳过豆瓣同步，仍保留播放日期，
后续同步和批量已看标记不会覆盖首次观看时间；旧队列优先接续已核验的库内季身份。

历史分季修复采用“预览 → 应用”，只更新明确指定的档案。应用前保存完整原始备份，
保留观看时间，有明确播放证据时可恢复首次观看日期；同季重复记录支持指定旧键合并并保留原记录。
预览后发生播放更新时要求重新预览，不覆盖新记录。历史修复不会重写豆瓣网站观看状态。

自动订阅保留明确季号，支持 `Season 6`、`6th season`、`S06` 和“第六季”等标题。
即将上映优先使用目标季已识别的首播日期，缺失时再查询 TMDB；续季和特别篇不使用
整剧第一季的首播日期兜底，日期仍缺失时留待下一轮重试。
“提前 10 天”表示首播前 10 天至首播当天的候选窗口，观察期、评分、地区等筛选仍同时生效。

## 注意

- 插件只处理插件自身的榜单、订阅、观察和归档记录，不修改 MoviePilot 核心数据结构。
- 外部豆瓣请求可能受到登录、验证码或风控限制；失败记录会保留在插件状态中。
- CookieCloud 兼容导入是当前 V3 宿主尚无稳定 SDK 出口的受审计例外，待宿主提供稳定
  出口后移除。
